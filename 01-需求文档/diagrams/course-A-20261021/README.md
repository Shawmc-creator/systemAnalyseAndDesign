# 现行业务建模图源

这些图对应需求文档2026-10-21第二批修订的A部分。每张图均包含可编辑的PlantUML源文件、SVG和用于LaTeX排版的单页矢量PDF。

- `business-overall`：7个对外业务用例的总体图。
- `buc-01`至`buc-07`：每个业务用例的独立图。
- `business-support`：3类内部支持流程及服务衔接。
- `business-current-1`至`business-current-10`：7个患者业务及3类内部支持的现状序列。
- `business-improved-1`至`business-improved-10`：对应的改进序列。
- `business-patient-flow`、`business-resource-flow`、`business-daily-flow`：患者全过程、接诊资源、开诊及日终活动图。

正文图号及PDF页码见`../../设计交付/整合版图表清单.json`；课程符合性和未确认事项见`../../设计交付/课程总结复核-A业务建模核验.json`。

打开`.puml`即可用PlantUML重新编辑及渲染，所用字体为宋体。已有配套矢量PDF，重新编译LaTeX正文时可直接使用。不同图使用适合内容的幅面，保持正文图中文字可读。

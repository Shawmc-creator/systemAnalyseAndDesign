## 重建图形

需要Python 3、Java、PlantUML、Graphviz以及Microsoft YaHei字体。导出矢量PDF还需Node.js、Playwright包和本地Chromium/Edge；通过`NODE_PATH`指向已安装的Node包即可。渲染过程只读取本地文件。

```powershell
python 生成数据库图.py --java D:/CS/jdk25/bin/java.exe --plantuml D:/CS/PlantUML/plantuml-1.2026.8.jar --browser 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'
```

省略`--browser`只生成源图和SVG；`--sources-only`仅生成源图。总图集合包含15个PlantUML文档；要重建拼版总图，请运行此脚本。主文档仍由LaTeX编译。

- `验证数据库设计.py`：只在临时目录建空库；126项检查包含实际业务正反例及库存/资金的两个连接竞争。
- `SQLite-隔离验证结果.json`：逐项结果及被测SQL摘要，66张表有场景数据。其余表已作结构准备检查，不能声称85表全部业务均已验收。

```powershell
python 生成建表设计.py
python 验证数据库设计.py --report SQLite-隔离验证结果.json
```

要求Python 3及SQLite 3.38以上且启用JSON，实际测试为SQLite 3.53.1。脚本不接收运行库路径，也不生成演示账号。调用方需启用foreign_keys和recursive_triggers，并按业务错误回滚整个事务。

库存流水触发器在同一事务更新余额和revision，应用不能再重复扣减。集合完整性、状态转移、当前资格、审计、原单额度、真实文件等剩余责任见实施边界与主文档4.1.9。

## 已完成的当前网页

- 前台：患者档案、预约改约、到诊、候诊时段/牙医/诊椅重新协调、复诊联系与真实预约关联，以及医保身份核验与登记。
- 牙医：本人接诊、健康复核、病历和所见、方案及分项患者决定、影像文书归属核对与明确版本关联、院内外处方及用药指导、原方药学退回的核实回复、实际治疗、签署与独立补充、实际结束交接、诊后评估。
- 收费人员：价目录入、原账目与付款、到账核实、预付抵扣、电子支付原单、费用申请及普通退款、医保预结算/结算/撤销与实际回款、日终核对。
- 负责人：排班、价目与待核价、费用审核、设备状态、材料单位及批次放行、基础供应商与采购确认、实际差异协调和盘点审批、经营及收付款核对、医保编码及原结算撤销范围核实、差异责任跟进。
- 药学岗位（机构条件及人员资格具备后）：院内审方、退回医师处理、批次核对、分批实际发药及用药交代。
- 诊疗助理：影像及文书上传归档与补件、资源准备与清洁核验，材料/批次/位置登记，基础采购与分批验收，领用、实际用料、未用退回、盘点重核及异常隔离。

# 青禾牙科诊所管理系统

面向三家门店的连锁牙科诊所课程项目，包含 Web 演示系统和系统分析与设计报告。演示使用虚构患者和业务数据。

## 在线演示

**访问网址**　[https://106.55.178.237/](https://106.55.178.237/)

首次访问前，请向项目提交人领取 `dental-preview-root.crt`。

1. 用 Edge 或 Chrome 打开上面的演示网址。如果出现证书警告，点击「高级」查看详情。若提示证书颁发机构不受信任，请按下一步导入根证书。已能看到登录弹窗时，可直接跳到第 3 步。
2. 将项目提交人提供的根证书保存到自己电脑的「下载」文件夹。在 Windows 命令提示符（CMD）中执行以下命令，将证书加入当前用户的「受信任的根证书颁发机构」。若证书保存在其他位置，请替换文件路径。

   ```cmd
   certutil -user -addstore Root "%USERPROFILE%\Downloads\dental-preview-root.crt"
   ```

   如果 Windows 弹出安全警告询问是否安装证书，确认文件来自项目提交人后，点击「是」。导入成功后，关闭并重新打开浏览器，再访问演示网址。若仍有证书警告，请联系项目提交人核对证书。

3. 浏览器弹出的登录框使用用户名 **`preview`**，密码 **`3578td1116iu`**。
4. 进入牙科系统后，使用演示密码 **`Clinic123`** 登录。演示账号为前台 `frontdesk`、牙医 `dentist`、收费 `cashier`、助理 `assistant`、负责人 `manager`。患者可以点击「患者自助预约」。

若试用设备无法导入私有根证书，可在 Windows 上使用下述本地入口。

## 本地启动

1. 下载本仓库，安装已验证的 [Node.js 24.19.0 LTS](https://nodejs.org/en/blog/release/v24.19.0)。
2. 运行根目录的 `07-启动连锁演示.cmd`，访问 [本地连锁演示](http://127.0.0.1:3011/)。
3. 岗位账号、门店权限及操作示例见[老师使用说明](00-老师使用说明.md)。

## 当前可演示的业务

- **患者和前台**：患者使用虚构身份自助预约、取消。前台办理建档、预约改约、到诊和复诊联系。
- **牙医和助理**：记录病历、治疗方案、实际诊疗、院外处方及影像文书。门店排班和诊椅状态参与接诊安排。
- **收费和负责人**：办理报价、登记收退款和核对款项，管理门店账号、排班、基础采购库存及经营统计。跨店病历查看需要授权。

**交付范围**：当前交付是课程演示版。收退款只登记系统外结果，医保使用一店虚构场景。正式连锁数据库迁移、真实患者身份核验、医保联网及院内发药尚未交付。

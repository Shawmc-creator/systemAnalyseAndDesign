## 快速演示

1. 双击 `01-一键启动系统.cmd`。
2. 等待浏览器打开 `http://127.0.0.1:3000/`。
3. 使用下列员工账号登录：

| 角色 | 账号 | 密码 |
|---|---|---|
| 诊所负责人 | `manager` | `Clinic123!` |
| 前台 | `frontdesk` | `Clinic123!` |
| 收费人员 | `cashier` | `Clinic123!` |
| 牙医 | `dentist` | `Clinic123!` |
| 两名诊疗助理 | `assistant`、`assistant2` | `Clinic123!` |

患者业务由工作人员办理。可在收费页查看待结算和现金找零示例，在复诊与材料页查看对应记录。详细修改与验证见 `02-系统实现/文档与代码对齐检查.md`。

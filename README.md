# 青禾牙科诊所管理系统

面向6名工作人员的小型牙科诊所，包含网页前端、Node.js后端、SQLite数据层及需求文档。功能按需求文档UC-01至UC-20落实，覆盖患者资料、预约到诊、病历和方案、实际诊疗项目、价目与现金结算、复诊随访、人员安排、材料及日常核对。

## 本地启动

需要Node.js 24或更高版本，前后端没有第三方npm依赖。克隆仓库后，在终端运行：

```shell
cd 02-系统实现/app
node scripts/seed-demo.js
npm start
```

打开[http://127.0.0.1:3000/](http://127.0.0.1:3000/)。Windows也可在安装Node.js后双击根目录的`01-一键启动系统.cmd`。网页需要后端服务运行。

## 测试

在`02-系统实现/app`运行：

```shell
npm test
```

新版结果为57项通过、0失败（含1个父测试容器），涵盖20个用例及版本、重复提交和事务回滚检查。自动业务测试使用独立内存数据库。

系统启动后，可运行：

```shell
node scripts/acceptance.js
```

它检查六账号、运行接口和演示闭环，并生成TXT／JSON验收证据到`04-测试与验收/测试结果`。测试范围与网页实测记录见验收文档第7节。

面向三家门店的连锁牙科诊所课程项目，包含 Web 演示系统和系统分析与设计报告。演示使用虚构患者和业务数据。

**访问网址**　[https://106.55.178.237/](https://106.55.178.237/)

1. 用 Edge 或 Chrome 打开上面的演示网址。如果出现证书警告，确认地址仍是 `https://106.55.178.237/`，点击「高级」，再点击「继续访问」或「继续连接」。直接看到登录弹窗时，进入下一步。
2. 浏览器弹出登录框后，输入用户名 **`preview`** 和密码 **`3578td1116iu`**。
3. 进入牙科系统后，使用演示密码 **`Clinic123`** 登录。演示账号为前台 `frontdesk`、牙医 `dentist`、收费 `cashier`、助理 `assistant`、负责人 `manager`。患者点击「患者自助预约」，使用账号 `patient`、密码 `Patient123` 登录。

**浏览器未提供「继续访问」时**，可向项目提交人领取 `dental-preview-root.crt`，保存到「下载」文件夹，再在 Windows 命令提示符（CMD）中执行以下命令。证书保存在其他位置时，需替换文件路径。

```cmd
certutil -user -addstore Root "%USERPROFILE%\Downloads\dental-preview-root.crt"
```

如果 Windows 询问是否安装证书，确认文件来自项目提交人后点击「是」，然后重新打开浏览器。如果设备限制安装证书，可使用下方的本地演示。

## 本地启动

1. 下载本仓库，安装已验证的 [Node.js 24.19.0 LTS](https://nodejs.org/en/blog/release/v24.19.0)。
2. 运行根目录的 `07-启动连锁演示.cmd`，访问 [本地连锁演示](http://127.0.0.1:3011/)。
3. 岗位账号、门店权限及操作示例见[老师使用说明](00-老师使用说明.md)。

## 当前可演示的业务

- **患者和前台**：患者登录后按门店、日历日期、时段、医生和就诊目的预约，也可取消本人预约。预约编号如 `A-1026-001`。前台办理建档、预约改约、到诊和复诊联系。
- **牙医和助理**：记录病历、治疗方案、实际诊疗、院外处方及影像文书。门店排班和诊椅状态参与接诊安排。
- **收费和负责人**：办理报价、登记收退款和核对款项，管理门店账号、排班、基础采购库存及经营统计。跨店病历查看需要授权。

**交付范围**：当前交付是课程演示版。收退款只登记系统外结果，医保使用一店虚构场景。正式连锁数据库迁移、真实患者身份核验、医保联网及院内发药尚未交付。

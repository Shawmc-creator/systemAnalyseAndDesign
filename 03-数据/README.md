# 数据说明

- 当前网页3001连接`02-系统实现/app/data/clinic-v2.db`，SQLite，版本20261022，共100张物理表。
- 现行设计以`01-需求文档/`中的需求PDF、69表核心模型及图为准。程序从已核验原SQL初始化，再通过`app/src/v2/`的升级脚本补齐业务；原SQL不作覆盖修改。本目录早期设计草稿不作为当前实施依据。
- 最新升级前一致性备份在`app/data/backups/before-settlements-*.db`。原91张表既有记录、411个原触发器已核对保留；较早备份继续作为历史资料保存。
- 影像文书原件在`app/data/clinical-files/`，与数据库共同保存才能恢复完整文件。不能仅备份数据库。
- 医保及院内药学机构配置为`app/data/insurance-config.json`、`pharmacy-config.json`；当前均未启用。运行数据、原件、实际机构配置及备份不进入源码Git仓库。
- `clinic.db`、本目录运行备份和早期示例导出属于历史资料，当前新版启动器不会把它们作为运行库打开。不要用旧种子或旧导出程序重置当前库。
- 不直接删除运行时WAL/SHM文件；使用SQLite一致性备份，或停止服务后完整保存运行数据。
- 3002支付医保演示只使用内存及虚构资料，不写实际业务库，不代表真实平台联网。最新流程见`02-系统实现/支付医保与经营核对验收.md`。

# 数据说明

## 连锁课程演示

作业推荐使用根目录 `07-启动连锁演示.cmd`（固定演示时间，端口 3011）或 `08-启动实时日期演示.cmd`（端口 3019）。两者分别使用 `02-系统实现/app/data/chain-demo/` 和 `chain-live-demo/` 的独立虚构快照，不打开或迁移下面所述的单店运行库。影像文书原件存放在相应快照旁的 `.files` 目录，保存或复制演示时应与快照一同保留。

GitHub 不包含运行快照、附件、数据库备份和 Node 运行时；从源码运行需要安装 Node.js 24 或以上版本，演示首次启动会初始化虚构数据。详细步骤见 `04-测试与验收/第一版主业务操作指引.md`。真实支付、医保联网和正式连锁数据迁移不属于目前的演示能力。

# 基础管理与参考价对齐验收

依据现行176页需求文档的UC-26“维护诊所基础资料与账号”和UC-11收费价目要求。本段完成对应代码的专项验收与修正，不增加新的业务模块。

## 已落实的业务

| 要求 | 实现及办理方式 |
| --- | --- |
| 职员与个人账号 | 负责人在“诊所基础管理”建立职员、独立账号和核实后的日常岗位；必须填写任职依据，不把创建账号视为取得医疗资格 |
| 授权与停用 | 支持授予、撤销、账号停用及恢复。停用使原会话失效；恢复后重新登录。原任职、授权及业务责任记录保留；药学任职继续由院内药学流程办理 |
| 当前资格显示 | 页面复用登录鉴权的实际有效性判断，包括账号、在岗期间、授权及资格期间；未撤销记录也可能当前不生效，不能误显示为有效权限 |
| 接诊资源 | 新诊椅进入目录后仍须发布排班才能预约。退役诊椅、停用牙医账号或撤销牙医岗位前，必须先协调有效排班及实际占用；临时故障、清洁仍走资源停用与恢复 |
| 收费分类与检索 | 项目按检查预防、牙体牙髓、拔牙外科、修复、正畸、药品、其他分类。旧项目没有分类依据时归“其他”，不猜测历史分类。负责人和收费人员使用同一份项目目录 |
| 参考价草稿 | 收费人员可选择12个示例，核实本诊所拟价和范围后仅建立草稿；须另行提交并由负责人确认。金额使用整数分，零元项目须有免收依据 |
| 项目身份与历史费用 | 已有价目或实际引用的项目不能改名称或计价单位来重新解释旧账。启停、分类调整保留历史价目及费用，停用后不能新建价目 |

参考价区分单牙、单面、材料范围和完整疗程。完整疗程示例明确说明复诊、保持器是否包含及预收款处理；复诊不能再次按完整疗程全额重复记费。示例不代表诊所正式价格或医保支付目录，不复制国外税务和保险规则。

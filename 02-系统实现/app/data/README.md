# 运行数据

当前3001网页使用`clinic-v2.db`，108张运行物理表，版本2026102303。最新升级前102表一致性备份为`backups/before-workflow-history-*.db`；原102表的行数及全部原列摘要核对保持，新增六张空历史表及五个设计关联列，不补造过去事件。费用、诊疗及更早备份继续保留。新库首次建立演示账号，已有运行数据不重复初始化。

影像与诊疗文书原件保存在`clinical-files/`，索引、版本、原文件名和摘要保存在当前数据库。保存或恢复数据须同时保留数据库及原件目录；只有数据库不能还原文件。原件目录不进入源代码Git仓库。

运行时可能存在`clinic-v2.db-wal`和`clinic-v2.db-shm`。备份应在停止服务后完整保存当前数据，或使用SQLite一致性备份配合原件保存；不要单独删除活动日志。

`clinic.db`、`backups/`及作业根目录`03-数据/运行备份/`中的早期库属于历史数据，当前启动器不会将其作为新版运行库打开。不要用旧版种子程序重置当前数据。

机构药学条件配置为`pharmacy-config.json`，默认不存在且不启用；示例见`../config/pharmacy-config.example.json`。根据已核实条件填写并重启后生效，人员资格另由负责人登记。保存运行数据时同时保存该配置；配置不进入Git源码仓库。

医保机构条件配置为`insurance-config.json`，默认不存在且不启用；示例见`../config/insurance-config.example.json`。核实机构条件并配置后仅开放人工核实官方终端结果，不代表自动联网。该配置不进入Git；独立3002支付医保演示只使用内存库，不写运行数据。

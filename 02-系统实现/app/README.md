## 启动

作业根目录双击`01-一键启动系统.cmd`，自动打开`http://127.0.0.1:3001/`。启动器检查Node版本、复用已运行的当前服务，未就绪时不打开网页。已有其他服务占用端口时报告问题，不停止其他程序。

```powershell
# 新库初始化六名演示工作人员；已有库不重复初始化
npm run demo:v2
# 使用已建立账号的当前库启动
npm start
```

没有全局Node时用`../runtime/node.exe src/v2/server.js --demo`。

账号：`manager`（负责人兼牙医）、`dentist`、`frontdesk`、`cashier`、`assistant`、`assistant2`。演示密码`Clinic123!`。

## 外部办理及机构条件

现行25个用例的本地流程已接入。当前通过人工核实官方终端原单办理支付医保，**没有自动连接银行、微信、支付宝或地区医保接口**。自动联网需对应商户、地区资料、适配及联调；页面明确显示未连接。

正常3001运行库的医保与院内药学条件均未启用，没有自动授予药学资格。医保配置示例见`config/insurance-config.example.json`，实际配置为`data/insurance-config.json`，药学条件使用`data/pharmacy-config.json`。核实机构条件、填写有效期并重启后开放对应人工办理；这些配置不进入Git。演示不代表真实资格或平台结果。

作业根目录`05-体验支付医保演示.cmd`使用隔离内存库及固定演示时钟，不会启用实际数据库的医保条件。本次业务历史批次已收尾，完整设计差异见阶段说明；Figma视觉改版仍暂停。

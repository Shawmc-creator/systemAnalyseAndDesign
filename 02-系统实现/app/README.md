## 数据

当前库`data/clinic-v2.db`，版本2026102601、108张运行物理表；上一版77个设计表的字段名、类型、可空、指定单列唯一、外键及主键盘点无差异；完整规则及设计分层仍须另行核对。升级前自动备份；本轮增加service.category，旧项目未核实的分类归“其他”，增加基础管理权限，原108表的原列和业务事实保持；医保旧数据若缺确切原提交或最终核实人依据，停止升级，不补造。

原件存放在`data/clinical-files/`，支持PNG、JPEG、PDF，每个文件最大10MB。保存或恢复当前数据时须同时保留数据库与该目录；源代码提交不包含原件。助理上传，牙医核实归属；补件保留旧版，不自动视为治疗同意。

历史复杂供货记录、签署内容、实收实退、库存流水保留原始记录。原85表SQL摘要继续核验；未知结构文件拒绝自动打开或迁移。

## 外部办理及机构条件

单店程序已接入 UC-27 独立报价相关流程。**没有自动连接银行、微信、支付宝或地区医保接口**；当前支付业务只登记核实结果。自动联网需对应商户、地区资料、适配及联调；页面明确显示未连接。

正常3001运行库的医保与院内药学条件均未启用，没有自动授予药学资格。医保配置示例见`config/insurance-config.example.json`，实际配置为`data/insurance-config.json`，药学条件使用`data/pharmacy-config.json`。核实机构条件、填写有效期并重启后开放对应人工办理；这些配置不进入Git。演示不代表真实资格或平台结果。

作业根目录`05-体验支付医保演示.cmd`使用隔离内存库及固定演示时钟，不会启用实际数据库的医保条件。本次医保字段及流程已对齐，D2其余分层见最新验收说明；Figma视觉改版仍暂停。

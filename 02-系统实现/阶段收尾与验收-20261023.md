| 业务 | 本次收尾结果 |
| --- | --- |
| 复诊随访 | 草拟与发布分开；保存发布、调整、转交、实际联系、继续跟进、完成及撤销快照。来源签署发布、取消预约恢复待联系也共同留历史 |
| 盘点 | 保存原账面与实点、版本不符、重新实点及负责人决定；重新实点清除当前审核结论，旧意见保留在历史中 |
| 采购验收 | 首次确认、待检后确认和负责人差异协调分别留存；历史连接本次合格增量的入库流水，零增量不产生入库 |
| 文书归属 | 原索引与正确归属的新索引成对保存；已确认原件由有权牙医重新确认，原确认意见与既有患者决定引用保留，不将旧引用改指另一患者 |
| 院内审方 | 逐次保存药学实际审方结论、意见及人员时刻；医师回复后重新审方不覆盖前次退回意见 |
| 医保预结算 | 分别登记原提交、已核实的成功结果和患者选择；原费用、正式结算连接确切提交，历史禁止改删。当前仍通过官方终端核实，不自动发起联网请求 |

新增六张表为`followup_history`、`stock_count_history`、`receipt_item_history`、`document_correction`、`prescription_review_history`和`insurance_preestimate_history`，均取自现行模型。历史通过独立存取类写入，与主结果、必要库存、请求回执及审计共同提交或回滚。同一提交重试返回原结果，不另增历史。不能恢复的旧业务快照不补造。

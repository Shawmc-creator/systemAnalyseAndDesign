# 青禾牙科预约演示

在微信开发者工具导入本目录，开发模式选「小程序」，项目选择「不使用云服务」。配置中的 `touristappid` 用于本地项目准备，使用手机预览和上传前，请通过工具选择自己注册的小程序 AppID。

1. 在「预约」选择二店、10 月 20 日和一个可选时段，点击「确认预约」。
2. 在「我的预约」查看新增记录，再点击「取消预约」并确认。
3. 回到「预约」，核对刚取消的时段可以重新选择。

默认预览使用小程序内的虚构排班，预约存于当前设备。

## 本机前台联调

1. 在 `02-系统实现/app` 目录运行 `node scripts/serve-miniprogram-trial.js`。服务使用独立内存数据库，监听本机 `127.0.0.1:3027`。
2. 在开发者工具的本地项目副本，把 `services/local-trial-config.js` 的 `enabled` 改为 `true`，并在项目的本地调试设置允许请求本机地址。重新编译后，预约页显示「本机联调」。手机预览仍使用本机演示数据。
3. 在模拟器选二店时段并预约。浏览器打开 <http://127.0.0.1:3027/>，用演示前台账号 `frontdesk` / `Clinic123` 进入二店「预约日程」，核对小程序显示的预约编号和状态。小程序取消后刷新网页，核对该预约变为「已取消」。

联调入口使用固定虚构患者和独立会话，退出服务后测试数据清除。

## 腾讯云真机体验

1. 用备案并可在微信公众平台登记为 `request` 合法域名的 HTTPS 地址作为 API 入口，例如 `https://api.example.com`。在 Caddy 中参考 `../app/cloud/Caddyfile.miniprogram.example` 增加 API 站点。该站点只开放小程序状态、登录、排班及预约接口。域名需要受信任的证书，域名证书可通过 Caddy 自动申请或由腾讯云签发后安装。
2. 在腾讯云启动演示后端的环境里配置下列变量，重新启动固定日期演示。AppSecret 和身份密钥由部署者在服务器上设置，保存在受保护的服务配置中。

   | 环境变量 | 内容 |
   | --- | --- |
   | `CHAIN_MINIPROGRAM_API_ORIGIN` | 公网 HTTPS API 地址，去掉末尾斜杠。Caddy 与后端使用同一地址。 |
   | `CHAIN_MINIPROGRAM_APPID` | 微信公众平台的小程序 AppID。 |
   | `CHAIN_MINIPROGRAM_APPSECRET` | 微信公众平台的小程序 AppSecret。 |
   | `CHAIN_MINIPROGRAM_IDENTITY_KEY` | 在服务器一次性生成并备份的 64 位十六进制随机密钥。重启时使用同一密钥，以便识别原有体验账号。 |

   注册 AppID 和域名的操作由小程序管理员完成。现有浏览器演示的 `CHAIN_DEMO_PUBLIC_ORIGIN` 单独配置。重启前按现有部署方法备份演示数据库与附件。
3. 启动应用和 Caddy 后，在服务器或电脑上执行 `curl.exe -fsS https://api.example.com/api/miniprogram/status`，将示例域名换成实际域名。返回 `status: ready` 表示 API 和 HTTPS 已连通。微信登录仍需用手机核对。
4. 在用实际 AppID 打开的项目中，将 `services/local-trial-config.js` 设置成 `{ enabled: false, apiOrigin: 'https://api.example.com' }`，填入实际 API 地址。恢复开发者工具的域名及证书校验，生成预览码，在手机上确认可获取排班。
5. 用两位体验者分别登录。第一位预约后，确认前台收到记录，第二位的「我的预约」仅显示自己的记录。第一位取消后，核对前台状态和时段。确认后上传代码并在版本管理选择体验版。

真机体验使用微信登录区分设备背后的账号，每个账号在演示数据库中对应一位虚构患者。数据库只留微信标识的密钥摘要，预约由现有门店和诊椅规则处理。用户界面无真实诊所挂号入口，使用虚构数据体验。微信正式发布还需核对主体、类目、隐私指引及备案状态。

# 新版首批实施与验收

日期：2026-10-18。依据已定稿的32用例、67实体、85表设计，首先接通前台业务。此记录不表示新版32用例已全部实现。

## 启动与演示

双击作业根目录`04-启动新版预约工作台.cmd`，打开`http://127.0.0.1:3001/`。

- 前台：`frontdesk`；负责人：`manager`；演示密码均为`Clinic123!`。
- 点击登录页的“前台演示”或“负责人演示”可直接进入对应岗位。
- 初次演示初始化六个账号、两张诊椅、两个同名患者和明日预约。前台点击“查看明日示例”可查询、通知、改约或取消。
- 当日到诊必须使用当日实际到院时间。负责人先发布当日可用排班，前台再办理现场到诊或当日预约到诊；不能把明日预约提前登记成今日已到诊。
- 命令行：在`app`目录运行`../runtime/node.exe src/v2/server.js --demo`；已有系统Node环境可用`npm run demo:v2`。
- 不带`--demo`时不会自动创建演示账号。正式人员初始化及账号管理将在运行管理模块接入，当前入口用于隔离演示。

旧版20用例程序继续使用3000端口和原启动器。新版使用独立文件`app/data/clinic-v2.db`，未迁移或改写旧运行库`clinic.db`。

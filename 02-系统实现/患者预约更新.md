# 患者预约更新

网页患者入口为 `/patient-demo`。演示账号为 `patient`，密码为 `Patient123`。

患者登录后选择门店、日历日期、30 分钟时段、可预约医生和就诊目的。预约列表显示患者姓名、医生、时间、状态与编号。编号由门店代码、预约月日和序号组成，例如 `A-1026-001`。

## 腾讯云更新

1. 保留当前部署目录和 Caddy 配置。在云服务器上停止该部署的 Node.js 演示进程。
2. 备份现有部署程序及 `02-系统实现/app/data`，包含原快照及演示附件。将新版包解压到独立目录。
3. 从新版包复制 `02-系统实现/app` 中的 `src`、`public`、`scripts`，覆盖原部署的同名程序文件。包中没有 `data`。已有演示数据会在新版首次启动时补齐预约编号和排班。
4. 从原目录按原 HTTPS 来源和小程序环境变量配置启动。进入 `/patient-demo` 核对患者姓名、门店余号和预约记录。服务本机 `/api/status` 应显示 `buildVersion` 为 `20261124-01`。
5. 如需回退，先停止新版 Node.js 服务，恢复备份的程序及快照，再用原配置启动。

## 小程序更新

小程序源代码在 `02-系统实现/miniprogram`。同步到微信项目时保留实际 AppID 和已有接口配置。未填写 HTTPS API 域名时，手机端使用本机虚构数据演示。配置微信后台登记的 HTTPS API 域名后，使用微信登录，与云端演示前台共用预约数据。
